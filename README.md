# DeepSeek-V4 中文阅读版

这个仓库整理了 DeepSeek-V4 technical report 的中文阅读材料，方便在浏览器中阅读或直接打印。

- HTML 在线阅读：<https://wojiuren.github.io/deepseek-v4-chinese/>
- PDF 打印版下载：<https://github.com/wojiuren/deepseek-v4-chinese/raw/main/DeepSeek_V4_Chinese_Print.pdf>
- 小学生注释版 PDF 下载：<https://github.com/wojiuren/deepseek-v4-chinese/raw/main/DeepSeek_V4_Chinese_kid_friendly_annotated.pdf>

- `index.html`: HTML 阅读版，图片和公式已内嵌，适合在线浏览。
- `DeepSeek_V4_Chinese_Print.pdf`: PDF 打印版，适合下载后打印。
- `DeepSeek_V4_Chinese_kid_friendly_annotated.pdf`: 小学生注释版，按“源页 + 结构化批注页”交替排版，适合初学者逐页阅读。
- `DeepSeek_V4_Chinese_kid_friendly_annotation_report.md`: 注释版合并报告，记录 18 个批次的合并结果。

说明：本仓库仅用于学习、阅读和排版整理。原始论文版权归原作者所有。
